# Solax desktop client

MyGo app with a web frontend. It is the entry point for the user: the conversation with the Super Agent, the workspaces and the machines.

## Requirements

- Go 1.27.3 (`go1.27.3` from smart-go-dl, or `GOTOOLCHAIN=go1.27.3`)
- Bun (MyGo runs `bun run dev:web` and `bun run build:web`)

## Commands

```bash
bun install
bun run dev          # mygo dev: Vite dev server + app, regenerates src/mygo.ts
bun run build        # package the app into build/
go1.27.3 tool mygo generate   # only regenerate src/mygo.ts
bun run typecheck
```

## Layout

| Path | Purpose |
| --- | --- |
| `main.go` | Binds the services and opens the window |
| `services.go` | Bound services: `Profiles`, `Super`, `Workspaces`, `Tasks`, `Machines`. They call the server with `pkg/client` |
| `stream.go` | The `/v1/stream` connection and the events for the page |
| `app.go` | Shared state: the profile store and the client of the profile in use |
| `internal/profile` | Server profiles; tokens in the OS keychain |
| `src/mygo.ts` | Generated by `mygo generate`. Do not edit |
| `src/api/` | `SolaxApi` (the only interface the views use) and its desktop implementation |
| `src/views/` | Chat, Workspaces, Machines, Settings |
